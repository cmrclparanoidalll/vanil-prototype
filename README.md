# Ваніль — прототип сайту

Статичний сайт: чистий HTML/CSS/JS, без збірки і без залежностей.
Відкривається подвійним кліком по `index.html`.

## Запуск

Найпростіше — відкрити `index.html` у браузері.

Якщо хочеться «як на сервері» (правильні відносні шляхи, кеш, тестування форм):

```bash
cd ~/Downloads/vanil-prototype && python3 -m http.server 8765
```

Далі http://localhost:8765

## Структура

| Що | Де |
|---|---|
| Стилі всього сайту | `assets/style.css` — єдиний файл |
| Уся поведінка | `assets/app.js` — меню, поява при скролі, калькулятор, форма |
| Дані проєктів і тексти сторінок | `_source/build.mjs` |
| Готові сторінки | `*.html` у корені — **генеруються, руками не правити** |
| Фотографії | `assets/img/` — 31 знімок Adobe Stock, ліцензовані на акаунт |

Раніше кожна з 14 сторінок містила власну копію 260 рядків CSS і по копії
навігації з підвалом. Тепер сторінки збираються з одного джерела:

```bash
cd ~/Downloads/vanil-prototype && node _source/build.mjs
```

Правите текст або дані в `_source/build.mjs` → запускаєте команду → HTML оновлюється.
Правите вигляд — прямо в `assets/style.css`, перезбирати не треба.

Старі `_source/legacy/` — початкові `_style.css` і `projects.py`, залишені для довідки.

## Що було полагоджено

- **Мобільне меню.** Нижче 1180px навігація просто зникала — на телефоні не було
  жодного способу перейти між розділами. Додано бургер із висувним меню.
- **Кнопка «Розрахувати вартість»** на головній вела на форму виміру замість калькулятора.
  Те саме — «Порахувати свою» на сторінці «Як це працює».
- **«Гардеробні» і «Меблі у ванну»** вели на сторінку з кухнями. Тепер відкривають
  калькулятор з уже обраним приміщенням (`rozrakhunok.html?room=wardrobe`).
- **Калькулятор не враховував приміщення** — гардеробна рахувалась за ціною кухні.
  Додано коефіцієнти: гардеробна 0,72 · ванна 0,85 · комора 0,6.
- **«Порахувати ще раз»** повертало на перший крок, але не скидало вибране.
- **«Назад»** зникало на екрані результату — виправити відповідь було неможливо.
- **Результат калькулятора тепер переноситься у заявку**: посилання «Записатись на
  вимір» підставляє в форму тип приміщення й показує пораховану суму.
- **Форма заявки** не перевіряла нічого. Тепер: перевірка імені й телефону з
  повідомленнями під полем, нормалізація номера в `+38 0XX XXX XX XX`, захист від
  повторного відправлення.
- **Поява секцій при скролі** трималась на IntersectionObserver і в частині випадків
  (стрибок до якоря, відновлена позиція, фонова вкладка) секція лишалась з `opacity:0`
  назавжди. Замінено на перевірку позиції, яка ловить і «перестрибнуті» секції.
- **Фотографії.** Одне фото цеху повторювалось на сайті 10 разів, банер під кожним із
  восьми проєктів був той самий, а підписи не збігалися з кадрами («Мийка винесена до
  вікна» стояла під шухлядами). Тепер 31 ліцензований знімок, у межах сторінки жодного
  повтору, у кожного проєкту свій банер, а герої підібрані під опис: острів лише там,
  де він є в специфікації.
- Дрібне: `<h1>` більше не лежить усередині `<span>`, підписи до фото стали
  `<figure>/<figcaption>`, у полів форми з'явились `name`, додано `description`,
  favicon і фокус-стани, на вузьких екранах підпис на фото більше не тисне кнопку.

## Що лишилось зробити перед бойовим запуском

- Заявка нікуди не йде — потрібен бекенд (у `assets/app.js` є місце для `fetch`).
- Фото — Adobe Stock, ліцензовані й лежать локально в `assets/img/` (по два розміри:
  `-900` для карток, `-2400` для панелей). Замінюються на власні зйомки без правок коду:
  досить покласти файл з тим самим іменем.
- Відео з головної прибрано: ролик, підписаний «цех», насправді показував бар.
  Замість нього кадр розкрою. Своє відео цеху можна повернути на це місце.
- Немає окремих сторінок «Гардеробні» і «Меблі у ванну» — поки що це калькулятор.
- Ціни в калькуляторі орієнтовні, коефіцієнти треба звірити з реальним кошторисом.

## Відоме обмеження: фотографії

Портфоліо зібране зі стокових знімків, і це видно: у кожного проєкту герой і
дві деталі — кадри з різних зйомок, тож вони не читаються як одна кухня. Окремі
невідповідності специфікації я вичистив (пальми за вікном у заміському проєкті,
гардеробна замість комори, дерев'яна стільниця під написом «кварц»), але
загальну різнорідність стоком не лікується.

Для бойового запуску потрібна власна зйомка: 8 проєктів × 3 кадри (загальний
план, робоча зона, деталь фурнітури), один світловий сценарій на всі. Файли
кладуться в `assets/img/` з тими самими іменами — код правити не треба.
